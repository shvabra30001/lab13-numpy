## Что делает
Программа демонстрирует создание массивов NumPy, векторные операции без циклов, расчёт статистики, работу с двумерными матрицами, фильтрацию через булеву маску и вычисление средних значений по осям (`axis=0` и `axis=1`).

## Как запустить
1. Установите зависимости: `pip3 install -r requirements.txt`
2. Запустите скрипт: `python3 main.py`
